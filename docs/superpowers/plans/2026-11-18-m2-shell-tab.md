# M2 — Shell Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The SHELL folder runs fish on a PTY with `TERM=vt100`. Its output goes through a virtual terminal and is redrawn on the WY-60 using only allowlisted bytes. The shell survives tab switches. Fullscreen resizes the PTY. `^] [` scrolls back through history and `^] p` toggles raw passthrough. Scrolling output costs a few bytes per line instead of a repaint.

**Architecture:**
- **Bytes in:** PTY bytes go through `AcsFilter`, which turns DEC line-drawing switches into Unicode box characters (`vt100` 0.18 ignores `ESC ( 0`). They then reach a `vt100::Parser`, the virtual screen and scrollback.
- **Bytes out:** each frame, `ShellTab` translates the virtual screen into ratatui cells. Colours become reverse/bold; Unicode becomes DEC graphics, ASCII transliteration, or `?`.
- **Backend:** `Wy60Backend` keeps two full grids: `want` (what ratatui asked for) and `shown` (what the WY-60 displays). It always emits `want ≠ shown`.
- **Scrolling:** a tab can leave a **scroll hint** ("rows a..b of my pane moved up k"). The backend first scrolls that band of full-width lines with DECSTBM + LF (or RI for down), shifts `shown` to match, and then repairs whatever differs. That includes sidebar cells the full-width scroll disturbed. A wrong hint costs bytes, never correctness.

**Tech Stack:** existing crates plus `deunicode` (transliteration). No new terminal emulator.

**Spec:** `docs/ARCHITECTURE.md` (Shell tab, Modes → passthrough, Keys, backend "DECSTBM scroll-region optimisation") and `docs/hardware.md` (keys, deferred wrap, Backspace `^H`).

## Scope notes
- **Windowed shell** is bordered and titled ` SHELL `, so the PTY is **59×38**. **Fullscreen** is borderless **80×43**, a true terminal.
- **Shell exit** turns the tab into `SHELL TERMINATED - PRESS RETURN TO RESTART`.
- **`^] ^]`** now also sends a literal `^]` (deferred minor from M1).
- **Gauge partial blocks** `▋▊▉` map to reverse space (deferred minor from M1).
- **Passthrough** forces the Shell tab to fullscreen, so the PTY is 80×43 and matches the real screen. `--strict` will log violations during passthrough; that's expected and documented.

## Global Constraints
- Output to the wire stays inside the `Vt100Dialect` allowlist (now including `ESC M`, reverse index), **except** raw passthrough bytes.
- Child environment: `TERM=vt100`, `MUTHUR=1`; the PTY's `VERASE` is `^H`, matching vt100 terminfo `kbs` and the WY-60 Backspace key.
- Keys follow `docs/hardware.md`. F1–F3 never reach the shell. PF1/PF3 → `ESC O P`/`ESC O R`, PF2 (Line Del/Char) → `ESC [ 3 ~`, Insert (PF4) → `ESC [ 2 ~`, Shift-F15/16 → `ESC [ 5 ~`/`ESC [ 6 ~`, Backspace → `^H`.
- Config `[shell]`: `command = "fish"`, `args = []`, `scrollback = 1000`.

## Review Focus
1. **`cat` of a large file in the windowed shell.** Bytes per scrolled line must be far below a repaint (< 200 B/line vs ~2.4 KB). Test: Task 2 `scroll_hint_beats_repaint` and Task 6 `shell_scroll_emits_hint`.
2. **A full-screen app using DEC line drawing** (`ESC(0 lqqk ESC(B`, as htop/dialog do with TERM=vt100). It must render as box lines, not `lqqk`. Test: Task 3 `acs_switch_becomes_box_drawing`, Task 6 `acs_reaches_screen_as_graphics`.
3. **The shell exits (`exit`).** No spin, no crash, and a restart works. Test: Task 4 `exit_is_reported`, Task 7 `shell_restart_after_exit`.
4. **A resize while a program is running.** The child sees the new size. Test: Task 4 `resize_reaches_child`.
5. **UTF-8 prompt glyphs from fish** (`❯`, `…`, accented letters). They reach the wire as sensible ASCII, never UTF-8. Test: Task 1 `transliterates_common_unicode`.

### Task 2: Backend shadow grids and scroll hints

**Files:** create `src/scroll.rs`; modify `src/backend.rs`, `src/lib.rs`.

**Interfaces — Produces:**
- `#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct ScrollHint { pub top: u16, pub bottom: u16, pub lines: i16 }`
  - Rows `top..bottom` (0-based, exclusive) moved **up** by `lines` (positive) or down (negative).
- `pub type HintSlot = std::rc::Rc<std::cell::Cell<Option<ScrollHint>>>`.
- `pub fn detect_shift(prev: &[u64], cur: &[u64]) -> Option<i16>`
  - Arguments are row hashes of the same pane.
  - Returns the shift `k` (±1..len/2) that maximises `cur[i] == prev[i + k]`, if that shift matches at least `len / 2` rows and more rows than `k = 0` does.
- Backend:
  - `Wy60Backend::new(writer, dialect, cols, rows)` is unchanged.
  - New `pub fn with_hints(self, slot: HintSlot) -> Self`.
  - Internal grids `want: Vec<CellState>` and `shown: Vec<CellState>`, where `CellState { glyph: Glyph, attrs: Attrs }` (post-mapping, so comparison is on wire output).
- `draw(diff)`:
  1. Apply the diff to `want`.
  2. If `slot.take()` is `Some(h)` and `h.lines != 0`, apply the scroll:
     - Up: `set_scroll_region(top, bottom-1)`, `cup(bottom-1, 0)`, then `lines` × `index`.
     - Down: `cup(top, 0)` and `|lines|` × `reverse_index`.
     - In both cases finish with `reset_scroll_region` (which homes the cursor, so track the cursor as `(0,0)`).
     - Shift `shown` rows within the band, filling with blank default cells.
  3. Emit every cell where `want ≠ shown`, row-major, with the existing cursor, attribute and charset coalescing, and set `shown = want` for those cells.
- `clear()` resets both grids to blank.
- `set_cursor_position` emits nothing when the tracked cursor is already there.
- Wide glyph handling from M1 stays: a wide `want` cell's continuation cells are stored as blank and compared like any other cell.

### Task 3: AcsFilter

**Files:** create `src/shell/acs.rs` and `src/shell/mod.rs` (just `pub mod acs;` for now); add `pub mod shell;` to `lib.rs`.

**Interfaces — Produces:** `pub struct AcsFilter`, `pub fn new() -> Self`, `pub fn filter(&mut self, input: &[u8]) -> Vec<u8>`.
- **What it tracks:** the G0/G1 designations (`ESC ( x`, `ESC ) x`), and SO (0x0e) / SI (0x0f) to pick which set is active.
- **Translation:** while the active set is `0` (DEC Special Graphics), bytes 0x5f–0x7e outside escape sequences become the UTF-8 of the matching Unicode. It's the inverse of the Task 1 / M1 table:
  - `q─ x│ l┌ k┐ m└ j┘ t├ u┤ w┬ v┴ n┼`
  - `` `◆ a▒ f° g± y≤ z≥ {π |≠ }£ ~· ``
  - `o⎺ p⎻ r⎼ s⎽`
  - `_` becomes a space.
- **Dropped:** the designation sequences and SO/SI. vt100 ignores them anyway.
- **Passed through untouched:** every other byte. The filter tracks escape-sequence state (CSI until 0x40–0x7e; OSC until BEL or `ESC \`) so it never translates bytes inside sequences.
- **Split input:** state persists across calls, so a sequence split between reads still works.

### Task 4: Pty

**Files:** create `src/shell/pty.rs`; add `nix` feature `"process"` and `"signal"` if needed.

**Interfaces — Produces:**
- `pub enum PtyEvent { Output(Vec<u8>), Exited }`
- `pub struct Pty { master: File, child: std::process::Child }`
  - `pub fn spawn(command: &str, args: &[String], cols: u16, rows: u16, events: impl Fn(PtyEvent) + Send + 'static) -> anyhow::Result<Pty>`. It:
    1. runs `openpty` with the winsize;
    2. sets the slave termios `VERASE = 0x08`;
    3. builds a `Command` with stdin, stdout and stderr all set to the slave, and env `TERM=vt100`, `MUTHUR=1`;
    4. in `pre_exec`, calls `setsid()` and then `ioctl(0, TIOCSCTTY, 0)`;
    5. starts a reader thread on a clone of the master. Each read becomes `Output(bytes)`; EOF or EIO becomes `Exited`, and the thread ends.
  - `pub fn write(&mut self, bytes: &[u8]) -> io::Result<()>`
  - `pub fn resize(&self, cols: u16, rows: u16) -> io::Result<()>` uses `TIOCSWINSZ` on the master; the kernel signals the child.
  - `Drop` kills the child (SIGHUP, then SIGKILL if it's still alive after 100 ms) and reaps it.

### Task 5: Key encoding for the shell

**Files:** create `src/shell/keys.rs`.

**Interfaces — Produces:** `pub fn encode_key(key: &Key, app_cursor: bool) -> Option<Vec<u8>>`.
- `Char(c)` becomes the byte for `c`. `Ctrl(c)` becomes the control byte (`c` & 0x1f; `]` → 0x1d). `Enter` → `\r`. `Backspace` → `0x08`. `Tab` → `\t`. `Esc` → `0x1b`.
- Arrows → `ESC [ A–D`, or `ESC O A–D` when `app_cursor` is on.
- `Home` → `ESC [ H`. `PageUp`/`PageDown` → `ESC [ 5 ~`/`ESC [ 6 ~`. `DeleteChar` → `ESC [ 3 ~`. `InsertKey` → `ESC [ 2 ~`.

- `F(4)` → `ESC O S`. `F(5..=16)` → xterm codes `15 17 18 19 20 21 23 24 25 26 28 29` + `~`. `ShiftF(n)` → `None`.
- `F(1..=3)` → `None` (the app consumes them). `Unknown` → `None`.

### Task 6: ShellTab

**Files:** `src/shell/mod.rs`.

**Interfaces:**
- Consumes `Pty`, `PtyEvent`, `AcsFilter`, `encode_key`, `detect_shift`, `ScrollHint`, `HintSlot`, and `Tab`.
- Produces:
  - `pub struct ShellConfig { pub command: String, pub args: Vec<String>, pub scrollback: usize }`
  - `pub struct ShellTab`
  - `pub fn new(cfg: ShellConfig, hints: HintSlot, events: impl Fn(PtyEvent) + Clone + Send + 'static) -> Self`. It starts the PTY lazily, on the first `render`, at that area's size.
  - `pub fn on_output(&mut self, bytes: &[u8])`
  - `pub fn on_exit(&mut self)`
  - `pub fn enter_scrollback(&mut self)`
  - `pub fn cursor(&self) -> Option<Position>`, in screen coordinates (`None` in scrollback or after exit)
  - `pub fn raw_mode_size() -> (u16, u16)` = `(80, 43)`
  - `impl Tab`
- **`render(area, buf)`:**
  - **Pane:** windowed (`area != full screen`) draws a border with title ` SHELL `, plus ` SCROLLBACK -N ` while scrolled back. The pane is the inner area, or the full area when fullscreen. If the pane size differs from the parser's, call `set_size` and `pty.resize`.
  - **Copying cells:** each vt100 cell becomes a ratatui cell. An empty cell becomes a space; a wide continuation is skipped. The modifier comes from:
    - `bold` → BOLD, `dim` → DIM, `underline` → UNDERLINED, `inverse` → REVERSED;
    - `bgcolor != Default` toggles REVERSED;
    - `fgcolor` is `Idx(8..=15)` or an RGB with luminance above 50 %, and `bold` is off → BOLD.
  - **Scroll hint:** hash each pane row (symbol + modifier). If `detect_shift(prev_hashes, hashes)` gives `k`, set the hint slot to `ScrollHint { top: pane.y, bottom: pane.y + pane.height, lines: k }`. Then store the hashes.
  - **After exit:** render `SHELL TERMINATED - PRESS RETURN TO RESTART` centred.
- **`handle_key`:**
  - In scrollback: PageUp/Up/PageDown/Down move by a page or a line (`set_scrollback`), and any other key leaves scrollback.
  - After exit: `Enter` respawns.
  - Otherwise: `encode_key(key, screen.application_cursor())` → `pty.write`.
- **`take_activity`:** true if output arrived since the last render.
- **`on_output`:** passes the bytes through `AcsFilter` and then `parser.process`.
